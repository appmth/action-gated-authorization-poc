# Judgment Demo Slide Specification (Video Use)

## Critical Constraints (MUST FOLLOW)

- NO background grid
- NO texture
- NO vertical or horizontal decorative lines
- NO presentation-style layout
- NO rounded card containers
- NO shadows
- NO gradients
- NO background patterns
- NO infographic style

White background only (#FFFFFF).

Slides must look like:
Real internal system screens.
Minimal admin UI.
Flat.
Neutral.
Technical.

This is NOT a marketing deck.
This is NOT a blog illustration.
This is a product demo visual.

---

## Typography Rules

- Japanese fully supported sans-serif font
- Clean and minimal
- No stylistic typography
- No decorative emphasis
- No oversized quote styling
- Tight and technical

---

# Slide 1: Title

Purpose:
Introduce concept quietly.

Layout:
- Plain white background
- Centered text block
- No container box
- No lines
- No divider
- No design elements

Text:

AI Agent を、
安全に、説明可能な形で
業務に導入する。

そのための基盤が、
Judgment です。

AI Agent should appear subtly as a small flat geometric illustration
(top-right corner, very minimal, monochrome line style).

---

# Slide 2: Execution Result

Purpose:
Everything looks normal.

Layout:
- Full-width system log UI
- No frame
- No card
- No rounded corners

Columns:
timestamp | agent | action | result

All result = success
No color highlight.
Black/Navy text only.

Make it look like a boring admin console.

---

# Slide 3: read_resident_record Detail

Purpose:
Show absence of reasoning.

Layout:
Plain technical detail panel.

Fields:
timestamp
action
target_id
result

Missing:
reason
role_context
justification

Empty values should appear as blank or “—”

No visual emphasis.
Absence should feel subtle.

assistant_agent
