# /review-pep

以下の PEP 実装（または設計）を、**AGAの観点でレビューしてください。**

## レビュー観点（必須）

### 1. 実行前ゲートになっているか
- Tool / API 実行の「直前」に存在するか
- バイパス可能な経路が存在しないか

### 2. PDP 依存が明確か
- 判断ロジックが PEP に混ざっていないか
- Allow / Deny を PEP が勝手に決めていないか

### 3. Context の扱い
- Context が明示的に渡されているか
- 暗黙・推測・LLM依存になっていないか

### 4. Explainability
- Deny 時に「理由」が返るか
- 人間が読んで理解できる文章か

### 5. AGA PoCとしての過不足
- PoCの目的に対して過剰ではないか
- 本質（実行前に止める）が薄まっていないか

## 出力形式
- 良い点
- 危険な点
- PoCとしての修正提案（最小）
