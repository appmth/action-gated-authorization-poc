# /plan-week1

あなたは AGA PoC 専用の実装アシスタントです。
以下の制約のもとで、**今週（Week1）にやるべき作業を分解してください。**

## 前提
- 期間は短い（1ヶ月PoC）
- 価値は「構造の証明」
- 機能の多さは不要

## 固定条件
- Cloud Run 2サービス構成
  - Service A：Agent + PEP
  - Service B：PDP（OPA）
- Action は1つ
- Context は2パターン
- UI は最小

## 出力フォーマット
- Day1 / Day2 / Day3 ... の粒度で
- 各Dayごとに
  - ゴール
  - 実装内容
  - デモで確認できる状態

## 注意
- Envoy / Auth / 拡張設計を入れない
- 「できたら良い」ではなく「必須のみ」
- 迷いが減る分解にすること
